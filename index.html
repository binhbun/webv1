iOS Signing & Installation Guides

How to Install ESign on iPhone

To install ESign, first complete any required device or DNS configuration, then select a currently available ESign signing option. Follow the installation instructions shown for your selected certificate and review iOS settings if the application is not immediately available after installation.

How to Install KSign on iPhone and iPad

KSign can be selected from the KSign tab above. Choose an available signing option, follow the installation flow, and verify the certificate status on your device before opening the application.

How to Configure DNS on iPhone

Some installation methods require a DNS profile or DNS configuration step. Install the required profile first, then return to the site and continue with the relevant ESign or KSign installation method.

Why Can an iOS Signing Certificate Stop Working?

Signing availability can change when a certificate expires, is revoked, or is otherwise no longer accepted by the device. When an option stops working, check the current certificate list and use another available signing method when appropriate.

Installing IPA Files on iPhone and iPad

IPA installation depends on the signing method, device configuration and current iOS restrictions. Use a supported signing workflow and follow the instructions provided for the certificate or installation tool you selected.

Frequently Asked Questions

What is ESign?

ESign is an iOS application used to install and manage signed applications on supported iPhone and iPad devices.

What is KSign?

KSign is an iOS signing and installation tool that can be used with supported signed applications and certificates.

Do certificate options always stay available?

No. Certificate availability can change. Check the current options on this page before starting an installation.
